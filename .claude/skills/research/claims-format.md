# Формат утверждений (state/claims.jsonl)

Одна строка — один JSON-объект. Добавлять через `python3 scripts/claims.py add` (id и created_at проставит скрипт).

```json
{"text": "По данным Банка России, в 2025 году объём операций без согласия клиентов вырос на 6,4%",
 "kind": "fact",
 "sources": [{"material": "M-07", "quote": "объем операций без добровольного согласия клиентов увеличился по сравнению с 2024 годом на 6,4%"}],
 "question": "Q2",
 "confidence": "high"}
```

| Поле | Значение |
|---|---|
| `text` | Одно проверяемое утверждение. Числа и имена — **как в источнике** (иначе `verify_claims.py` понизит до гипотезы). |
| `kind` | `fact` · `hypothesis` · `forecast` · `synthetic` |
| `sources` | `[{"material": "M-xx", "quote": "дословная цитата от 4 слов и 20 знаков до 300 знаков"}]`; для источника без снимка — `{"url": "..."}` (тогда это не факт) |
| `origin` | `source` (из источника) · `agent` (вывод агента) · `human` (сказал РП) · `synthetic`; по умолчанию выводится из sources |
| `basis` | для прогноза и вывода: ID утверждений-оснований |
| `contradicts` / `supports` | ID утверждений, которым это противоречит / которые подтверждает (нужно для пересмотра решений) |
| `question` | к какому вопросу плана относится (Q1…) |
| `confidence` | `high` · `medium` · `low` |

Правила:
- Заявление компании о себе: «МегаФон сообщает, что …» — факт о заявлении.
- Синтетика (модельные респонденты) — только `kind: synthetic`, материалы `--kind synthetic`. Не основание факта.
- Устаревшее не удаляется: `claims.py supersede C-003 --by C-015 --reason "..."`, `claims.py retract C-004 --reason "..."`.
- Источник, который скрипт не может открыть (личный кабинет, пейволл), подтверждает только РП: `python3 scripts/claims.py human-verified C-006 --note "..."` (точно в такой форме — Claude Code спросит разрешение у РП). Подтверждение пишется в `state/human.jsonl` с хэшем текста; если текст утверждения потом изменится, подтверждение перестаёт действовать. Поле `verified` через `add` поставить нельзя.

Что проверяет код (`scripts/verify_claims.py`, без LLM) и что понижает факт до гипотезы:
- цитата короче 4 слов или 20 знаков (`short_quote`): цитата «Ева» ничего не подтверждает;
- проценты и квантификаторы утверждения («гарантированно», «полный», «все», «всегда», «любой», «каждый», «никогда», «без исключений», «100%») должны стоять в самой цитате (`not_in_quote`), а не где-то в снимке; остальные числа и имена — в предложении цитаты (`not_in_snapshot`);
- все источники факта — форум, блог, отзывы, соцсети (`ugc`) или реклама продавца о себе (`advertising`) (`weak_source`). Тип источника пишет `fetch_source.py --source-type …` в `materials/MANIFEST.json`; без флага он угадывается по адресу и названию, иначе `unknown` (такой источник проверка считает обычным). Реклама понижается, а официальное заявление компании (`official`) — нет: «МегаФон сообщает, что …» — проверяемый факт о заявлении, а промо-страница — нет;
- смысл («подтверждает ли источник вывод») код не проверяет — это делает source-reader и РП.
