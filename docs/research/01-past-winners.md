# 01. Прошлые победители: конкурсы ИИ-агентов и кейсы телекома

Роль: winners-scout. Режим: глубоко (~16 поисков, ~10 открытых страниц). Дата: 11.11.2026.

## TL;DR
- **Прошлых итераций этого конкурса и хакатонов «Фабрики продуктов МегаФона» в открытом доступе нет.** Публичные следы МегаФона как кейсодержателя: Big Data Challenge (2018), BigDataCamp (2020), «Цифровой прорыв» 2019 (кейс ЖКХ). Всё это старые события про данные, не про агентов. Значит, вкусы жюри берём из текста кейса: 4 критерия и §5 «каждый компонент должен оправдывать свою сложность пользой». Внешние аналогии слабее, чем бриф.
- **Хакатоны Anthropic «Built with Opus 4.6/4.7» (2026) выигрывали отраслевые эксперты, а не разработчики:** юрист, кардиолог, врач, инженер-ремонтник. Решали глубокое знание предметной области, упакованное в skills и файлы знаний, и измеримый эффект. У CrossBeam (1-е место): 13 skills, 28 справочных файлов, маршрутизатор подгружает 3–5 файлов на запрос (по вторичному источнику). У MaestrIA (приз «Keep Thinking»): файл знаний, собранный по интервью, поднял eval с 74% до 81% без правки промпта. Для нас: методическая база знаний плюс маршрутизация и замеренный прирост от них, и это прямо закрывает критерии 2 и 4.
- **Жюри агентных конкурсов всё чаще официально оценивают стоимость и документацию.** В Berkeley AgentX (2026) есть критерии «Cost Efficiency — API calls, compute time, token consumption», «Generality — across the full range of tasks» и «Technical Quality — documentation». На российском «Цифровом суверенитете 4.0» (май 2026) командам с ИИ-агентами вели в GitHub учёт часов, моделей, тикетов и токенов. Для нас: журнал стоимости и прогон на второй, недемонстрационной задаче выглядят нормой, а не украшением.
- **Корпоративные жюри в РФ (пример: ЮMoney, AI-хакатон по мультиагентным системам) выбирают «готовый продукт с понятной экономикой» и работающее демо.** В жюри из 5 человек двое были менеджерами продукта. Наше жюри тоже продуктовое (Фабрика продуктов), поэтому [вывод] стратегию будут читать как продакты: связь пользы с деньгами, честные отказы, план проверки.
- **Победитель Codex-хакатона (deepsense.ai) вывел паттерны «обвязки»:** короткий AGENTS.md как вход, база знаний в репо, контекст строго под задачу, проверки, повторяющиеся ошибки превращаются в постоянные ограничения. Это ровно форма нашего сдаваемого репозитория. «Огромный набор агентов и skills» (everything-claude-code: 71 агент, 314 skills) уже занят и прямо противоречит §5 брифа.

Ещё на MS AI Agents Hackathon 2025 (570 работ): Best Overall у **RiskWise** (агенты сканируют новости и графики поставок, флагуют риски), **Konveyor** (передача знаний с ответами со ссылками на источник), **ModelProof** (две LLM на запрос и аудит галлюцинаций с отчётом о надёжности). Критерии: innovation, impact, technical usability, category alignment; инновация 20%, вопрос «ИИ центральный или добавка».

Российские аналоги:
- **ЮMoney, внутренний AI-хакатон по мультиагентным системам (осень 2025, статья 01.2026).** Победил «Мультиагентный помощник SOC-аналитика»: берёт инцидент из трекера, обращается к системам, уточняет у сотрудников, выносит вердикт. Жюри назвало его «технологическим прорывом» с готовым продуктом и понятной экономикой. Критерии: «качество и структура презентации и наличие работающего демо».
- **«Цифровой суверенитет 4.0», РТУ МИРЭА, май 2026, кейс «Газинформсервиса»: воссоздать продукт только ИИ-агентами.** Победила команда MLlocomotive за «самую зрелую архитектуру и доменную модель». Отдельно отметили команду с лучшим отчётом. Все вели в GitHub учёт: состав, часы, модели, тикеты, число токенов.

## Что реально в репозиториях
- Репозитории CrossBeam, Elisa и Conductr открыты, по правилам Opus 4.6 это было обязательно: «Everything shown in the demo must be fully open source». Код я не открывал (бюджет). Цифры по skills и файлам CrossBeam взяты из вторичного обзора [не проверено по репо].
- **everything-claude-code (affaan-m)** вторичные сайты называют победителем хакатона Cerebral Valley × Anthropic. README этого не подтверждает: в нём нет упоминания хакатона [не проверено]. Содержимое README: 71 субагент, 314 skills, 98 команд, хуки для сессионных сводок и «continuous learning», Memory Vault в Markdown, раздел Token Optimization («Agent usage can be expensive if you don't manage token consumption»). [вывод] Это библиотека для разработчиков, а не продукт под задачу. Масштаб в нашем конкурсе не ценится (§5 брифа).

### Паттерны победителей
| Паттерн | Где видно | Значение для критериев кейса |
|---|---|---|
| Экспертиза предметной области, упакованная в знания (skills, reference-файлы, интервью) | CrossBeam, MaestrIA, PostVisit, Medkit | Кр. 1 (проработанность) и 2 (база знаний) |
| Маршрутизация: грузить только нужный контекст | CrossBeam (3–5 файлов из 28), deepsense (контекст под задачу) | Кр. 2 (маршрутизация), кр. 4 (экономичность) |

| Человек в контуре, ИИ не решает за него | PostVisit (под контролем врача), Maieutic (встречные вопросы) | Кр. 4 «может остановить, уточнить, исправить» |
| Реальный адресат проявил интерес (пилот, внедрение) | CrossBeam, Medkit, ARIA | [вывод] Аналог у нас: демо на настоящем брифе МегаФона |
| Учёт ресурсов как часть сдачи | AgentX (Cost Efficiency), «Цифровой суверенитет 4.0» (токены в GitHub) | Кр. 4 «известны время и расходы» |

### Чего избегать
- Демо только на одной задаче. AgentX явно штрафует узость («Generality»), наш кр. 3 требует «новых задач».
- Сложность ради сложности: десятки агентов и skills без доказанной пользы (кейс everything-claude-code как антипример для нашего жюри) [вывод].
- Слабое описание процесса. На «Цифровом суверенитете» отдельно отметили команду за отчёт, в ЮMoney критерий «качество и структура презентации» [вывод: при заочной оценке описание и видео заменяют защиту].
- «we use Opus for chat» не засчитывается (правила Opus 4.6): нужно использование возможностей среды (skills, hooks, субагенты, кэш, длинный контекст).

### Заезженные идеи в теме
- «Deep research агент со ссылками» (Apollo, FlowFacts, Research Pilot на lablab): поиск со ссылками сам по себе уже не выделяет.
- «Мега-набор skills/агентов для Claude Code» (everything-claude-code и клоны на claudepluginhub).
- «Генератор PRD/стратегии одним промптом»: на хакатонах не побеждал, победители шли в глубину домена [вывод].

## Вне скоупа
- Паттерны «harness engineering» от OpenAI и deepsense.ai (AGENTS.md как вход, проверки, ошибки → ограничения) пригодятся tech-scout.
