# Журнал решений

**Что берём.** Запись решения (ADR, Nygard): контекст → решение → последствия → статус (предложено, принято, заменено). Bezos: решения «первого типа» необратимы — нужен глубокий анализ; «второго типа» обратимы — решаем быстро и проверяем.

**Как применяем.** В `state/decisions.md` у решения есть основания (ID утверждений), kill-критерии из плана проверки и дата пересмотра. `scripts/revisit.py` находит решения, чьи основания понижены, отозваны, заменены или оспорены новыми утверждениями, и предлагает пересмотр.

**Источники.** M. Nygard, «Documenting Architecture Decisions», 2011. J. Bezos, письмо акционерам Amazon, 2015.
