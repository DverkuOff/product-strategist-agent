# Уровни доказательности и чек-лист недоверия

**Статусы утверждений (сквозная разметка всех документов).**
| Статус | Что это | Требование |
|---|---|---|
| факт | наблюдаемое, опубликованное источником | источник + сохранённый снимок в `materials/`; числа и имена есть в снимке (`verify_claims.py`) |
| гипотеза | предположение, которое можно проверить | формулировка проверки; кто/как проверит |
| прогноз | ожидание о будущем | основания (`basis`: ID утверждений) и горизонт |
| синтетика | ответ модельного респондента | только для гипотез и гайдов интервью, никогда не основание факта |

- Заявление компании о себе — факт о заявлении («МегаФон сообщает, что…»), а не независимо проверенный факт о мире.
- Вывод агента без внешнего источника — гипотеза (`origin: agent`). Прежний ответ агента не становится фактом.
- Статус «проверено человеком» (`claims.py human-verified`) — для источников, которые скрипт не может открыть (пейволл, личный кабинет).

**Чек-лист недоверия CPO** (почему исследованиям не доверяют, Lyssna 2026, n=107): малая выборка (49%), подобранные под вывод находки (45%), нет статистики (42%), неясная методика (37%), автор не может защитить подход (29%), противоречие другим данным (24%).
