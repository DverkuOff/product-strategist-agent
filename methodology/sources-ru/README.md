# Источники рынка РФ: паспорта и известные конфликты

Зачем: открытые цифры по одному рынку часто расходятся из-за разных методик. Агент не выбирает «удобную» цифру молча: показывает обе, объясняет разницу методик и помечает спорную цифру (не факт без оговорки).

| Карточка | Что даёт | Известный конфликт |
|---|---|---|
| [cbr-fraud.md](cbr-fraud.md) | Банк России: операции без согласия клиентов, мошеннические номера | ЦБ 29,3 млрд ₽ за 2025 год против оценки Сбера 275–295 млрд ₽ |
| [online-cinema.md](online-cinema.md) | ТМТ Консалтинг, TelecomDaily: онлайн-кинотеатры | 189 против 220,1 млрд ₽; спор о 54 млн подписчиков |
| [mediascope.md](mediascope.md) | Mediascope: аудитория и медиапотребление | данные через СМИ, методика панели |
| [company-disclosures.md](company-disclosures.md) | отчётность и интервью компаний (МегаФон и др.) | заявления компании о себе ≠ независимые данные |

Общие правила: первичный источник лучше пересказа в СМИ; дата и период цифры обязательны; «по сниппету» (страница не открыта) — не факт.
