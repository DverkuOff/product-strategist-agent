# Mediascope: аудитория интернета и медиапотребление

**Что даёт.** Охват интернета и отдельных площадок, время в сети (панельное измерение). Пример: 105 млн пользователей, 86% населения 12+ (10.2025); 4 ч 21 мин в день в сети [через СМИ, по сниппету, сверить].
**Ограничения.** Публично доступны в основном пересказы в СМИ; панель и возрастные рамки (12+, 15+, города 100k+) различаются между выпусками — сравнивать только одинаковые рамки.
**Как использовать.** Для оценки охвата каналов коммуникации; цифра без указания рамки (возраст, тип населённого пункта, период) — не факт.
