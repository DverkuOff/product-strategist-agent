# Онлайн-кинотеатры: ТМТ Консалтинг и TelecomDaily

**Известный конфликт (2025 год).** Объём рынка: 189 млрд ₽ (+39%; подписка 182,6 млрд ₽) по ТМТ Консалтинг против 220,1 млрд ₽ (+29,2%; подписка 165,9 млрд ₽) в другой оценке. Число подписчиков 54 млн по TelecomDaily — «Кинопоиск» назвал эту оценку «категорически неверной» [по сниппету, сверить по первоисточнику].
**Почему расходится.** Разный охват игроков (включение ТВ-приставок, бандлов операторов, рекламной модели), разные способы оценки выручки непубличных компаний, подписчик vs. подписка (одна семья — несколько подписок).
**Как использовать.** Не складывать и не усреднять. Указывать, чья оценка и что входит; для решения важна динамика внутри одной методики.
