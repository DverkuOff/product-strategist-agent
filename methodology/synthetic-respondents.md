# Синтетические респонденты: где можно, где нельзя

**Что берём.** NN/g: синтетические пользователи льстят, дают поверхностные ответы, переоценивают концепции, не дают поведенческих данных и плохо представляют нишевые группы. Годятся для генерации гипотез, проверки понятности вопросов и черновика гайда интервью. Бриф кейса: синтетические ответы не выдаются за реальные и не доказывают спрос.

**Как применяем.** Каждая реплика помечена `synthetic`, материалы — `kind: synthetic`, утверждения — `kind: synthetic`. `verify_claims.py` понижает факт, опирающийся на синтетику. Результат синтетического интервью — список гипотез и улучшенный гайд для реальных интервью.

**Источник.** M. Rosala, K. Moran, «Synthetic Users: If, When, and How to Use AI-Generated Research», NN/g, 2024: https://www.nngroup.com/articles/synthetic-users/
