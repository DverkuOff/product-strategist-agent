# Сценарий видео (до 10 минут)

Сюжет по требованиям кейса: запрос → работа агента → варианты → стратегия → продолжение после перерыва.
Демо-проект — официальный бриф МегаФона «Связь для близких и собственных устройств» (`projects/demo-svyaz-dlya-blizkih/inbox/brief-megafon.pdf`).

**Как записывать.** Живой прогон на той же задаче заново, в новой папке задачи, чтобы готовый результат в `demo-svyaz-dlya-blizkih/` остался эталоном прогона 21.11. Полный путь — около 35 минут работы агента, в видео ожидания ускоряем (×8–×16, с подписью «ускорено»), ответы РП и выводы — в реальном времени. Экран: Claude Code слева, редактор с `out/` справа. Голос за кадром, без музыки.

Подготовка (до записи, не в кадре):
```bash
python3 scripts/project.py new brief-video "Связь для близких: кому помочь первым"
cp projects/demo-svyaz-dlya-blizkih/inbox/brief-megafon.pdf projects/brief-video/inbox/
claude    # один раз принять доверие к папке, выйти
```

## Ответы РП (что печатать в кадре)

1. Запрос: «Я руководитель направления семейных услуг. Бриф в inbox/brief-megafon.pdf. Две группы клиентов — семьи с общим пакетом и владельцы нескольких своих номеров. Надо решить, кому помочь первым, что изменить и стоит ли вкладывать деньги; к концу Q1 решение о пилоте, к концу Q2 — расширять или нет. Итог одним документом из пяти частей, как просит бриф.»
2. После лестницы вопросов: «1а, 2а, 3а, 4б, 5а. Подтверждаю.» (или «как рекомендуешь»).
3. План исследования: Claude Code спросит разрешение на `project.py approve-plan` — нажать «да», затем «Начать. Добавь синтетические интервью: организатор группы, пожилой участник, владелец телефона и роутера.»
4. Выбор варианта: «Берём B с контрольной группой и kill-критериями. Добавь путь привлечения и прогноз по пяти строкам таблицы брифа. Дальше сам до конца, итог — документ из пяти частей.»

## Чек-лист перед записью
- [ ] `python3 -m unittest discover -s tests` зелёный.
- [ ] `pdftotext` установлен (`brew install poppler`): без него PDF читается хуже.
- [ ] Один раз открыть `claude` в папке и принять доверие (иначе разрешения проекта не действуют).
- [ ] Обычный режим разрешений, не auto: в auto хук отклоняет команды утверждения РП.
- [ ] Шрифт терминала крупный, тёмная тема, скрыты личные данные и токены; личный `.claude/settings.local.json` со своей строкой состояния убрать.
- [ ] После записи сверить время и стоимость нового прогона с README (эталон 21.11: ≈32 мин, ≈ $5,78).
