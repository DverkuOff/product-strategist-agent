## D-001 · Пилот «ручного режима» для семейных групп без разработки (вариант D)
- Дата: 2026-11-21
- Статус: принято
- Кто решил: РП (руководитель направления семейных услуг) выбрал вариант D («D. Дальше иди сам до конца»)
- Вариант: D (из out/options.md)
- Решение: первыми помогаем организаторам семейных групп; пилот без разработки на отобранных группах со случайным выбором и контролем, ветки разведены (уведомления организатору; текст приглашения как проверка варианта E); участвуют только группы с оформленным согласием участников на показ нужных полей; решение о разработке B или E — в конце Q2 по результатам пилота. Окно разработчиков Q2 используется только для подготовки данных о причинах перебоев
- Вердикт: делать — пилот дёшев, по затратам обратим и измеряет то, чего не хватает для выбора между B, C и E: частот проблем, влияния на активацию и оплату; безусловным «делать» остаётся только пилот, но не разработка
- Основания: C-088, C-018, C-070, C-071, C-044, C-082, C-013, C-091, C-089, C-080
- Что заставит пересмотреть: kill-критерии плана проверки (`out/validation-plan.md`): T-05 у вашего оператора уже есть все три функции организатора (уведомление о перебое, пояснение списаний, напоминание о приглашении); T-04 причина перебоя известна менее чем в половине событий или данные позже суток; T-07 меньше 400 подходящих групп за шесть недель; T-01 юридическая проверка не подтверждает доказуемое согласие участников и мгновенный отзыв (C-070, C-071); данные о причине перебоя и статусе платежа недоступны (C-088); в кабинете вашего оператора уже есть уведомление организатору о перебое и пояснение списаний (C-079); поток подходящих групп не даёт нужной мощности (C-091); после отзыва согласия организатор продолжает видеть сведения участника (C-020) — пилот приостанавливается; по итогам пилота: разница в доле активированных групп с контролем меньше 5 п.п. и T-02 без эффекта — разработку B и E не запускаем; оценка разработки выше 2,5 млн руб. при базовом эффекте — разработку не запускаем (T-08). Пороги предложены агентом и приняты по умолчанию (D-002)
- Пересмотреть до: 2026-12-31

## D-002 · Точки утверждения по умолчанию (поручение РП)
- Дата: 2026-11-21
- Статус: принято
- Кто решил: РП поручил агенту брать собственные рекомендации на точках утверждения («на точках утверждения бери свои рекомендации и запиши их как решения РП по умолчанию»); каждая такая точка отмечена в этой записи и в `state/journal.md`
- Вариант: D (из out/options.md)
- Решение: отказы и ключевое сообщение (этап стратегии), решение о запуске пилота и kill-критерии (этап проверки) принимаются по рекомендации агента как решения РП по умолчанию и показываются РП в конце; РП может изменить любое из них скиллом revise
- Вердикт: нужна ясность — решения по умолчанию не заменяют согласие РП: подтверждение конкретных отказов, ключевого сообщения и kill-критериев остаётся за РП
- Основания: C-088, C-018, C-091
- Что заставит пересмотреть: РП возражает против любого пункта по умолчанию; появление данных, меняющих основания D-001
- Пересмотреть до: 2026-12-31
